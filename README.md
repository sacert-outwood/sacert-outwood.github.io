# SACERT-OUTWOOD

This project is a site designed to highlight the work done by the St. Anselm's College Heritage and Historical Society to research the story behind Outwood House.

## Development

### Requirements

Go 1.24+

### Instructions

1. Run command `go run main.go`
2. Then open `http://localhost:8080`

## Production

The site is designed to run in Docker behind a reverse proxy.
